# Neon Mirror Draw / 霓虹镜像绘制

一个支持镜像与自由绘制的霓虹粒子交互画布。拖动鼠标或手指即可绘制，轨迹会自动平滑，并生成光带、星芒、粒子迸发与烟花消散效果。

An interactive neon-particle drawing canvas with optional mirror symmetry, automatic curve smoothing, glowing trails, sparkles, particle bursts and firework-like fading.

## Features / 功能

- 镜像与自由绘制模式 / Mirrored and free drawing modes
- 鼠标与触控支持 / Mouse and touch support
- 自动曲线平滑 / Automatic curve smoothing
- 霓虹光带、星芒与粒子尾迹 / Neon trails, sparkles and particle tails
- 绘制结束后持续迸发并消散 / Lingering firework emission after drawing
- 响应式电脑与移动端布局 / Responsive desktop and mobile layout

## Usage / 使用

直接打开 `index.html`。无需安装依赖。

Open `index.html` directly. No dependencies or build step are required.
